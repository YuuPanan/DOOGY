## 后续验收和扩展

| 项目 | 条件 |
| --- | --- |
| 原生终端完整验收 | 在目标Android设备/API及后续iOS分别核对录音权限、系统选择器、音视频和可听输出、分享、键盘、前后台及完整表单；SDK桩不代替终端 |
| 硬件独立上报 | 确定设备/供应商和协议，提供样机、授权测试凭据、时间/坐标/质量/补传样例，核对手机离开后的独立联网和解绑重绑 |
| BLE与固件动作 | 确定近场身份、配对和能力声明，真实核对声响/召回/单次定位、命令版本与回执；不编造UUID、topic或永远成功结果 |
| 真实模型、地图与渠道 | 提供授权服务、区域部署和真实响应，验证失败/权限/版本/送达证据；接口存在不代表已接入 |
| 产品规则 | 身体观察保持原文不评分；心率/睡眠分段/续航/运动或饮食公式、静音升级、权益支付等由产品与真实数据确认 |
| 生产和家庭试点 | 明确身份隐私、签名/发布、监控/值守、备份RPO/RTO、容量、样机和现场误报漏报及暂停条件 |

## 变更规则

新增接口或修改字段时同步 `fb.md`、模块合同、客户端调用与测试；数据库变更提供双驱动增量。普通配置和业务库不作为联调fixture，删除/恢复只在独立合成目标中验证。
