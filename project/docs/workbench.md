# 本地 Web 体验台

体验台把已有业务 API 串成主人可操作的浏览器流程：登录 → 选择宠物 → 查看概览与待办 → 记录照护 → 观察活动 → 管理设备。页面由现有 NestJS API 提供，使用本地 HTML、CSS 和原生 JavaScript，无额外前端服务、npm 依赖、地图 SDK 或外部 CDN。

首次展示可双击项目根目录的 [start-demo.bat](../start-demo.bat)，或运行 `start.bat demo`。它创建独立 SQLite/offline 合成样例，不使用用户原业务库；打开本次终端打印的地址，在登录页点击「主人演示登录」或「只读演示登录」。账号、五分钟步骤及继续上次演示的方法见 [MVP 演示指南](mvp-demo.md)。下文的普通启动继续读取原有环境与业务数据。

## 启动与登录

使用自己的业务数据时，在 Windows 双击项目根目录的 `start.bat`，或在 PowerShell 执行：

```powershell
./start.bat
```

等 API 与 Worker 就绪后，打开终端打印的体验台地址。默认 SQLite 配置为 [http://127.0.0.1:3000/app/](http://127.0.0.1:3000/app/)；已有 PostgreSQL 配置可用 `start.bat .env.postgres`，其示例端口对应 [http://127.0.0.1:3002/app/](http://127.0.0.1:3002/app/)。终端按 Enter 或 Ctrl+C 结束本次启动的服务。

启动沿用既有环境文件，先编译最新源码，再准备数据库并启动 API/Worker。页面显示当前数据模式与数据库驱动，供确认正在使用哪套数据；页面不修改这些配置。offline 模式没有外部业务调用。完整启动与配置说明见 [README](../README.md)。

登录页会标明普通/演示环境及当前访问地址。普通环境使用你在该数据库注册的账号，不提供演示快捷登录，也不自动创建内置账号和样例。展示 MVP 要使用 `start-demo.bat` 的新地址，不能固定使用普通 `3000` 端口。若需核对，在当前地址把 `/app/` 换成 `/api/v1/health`：演示为 `demo: true` 且带 `demo_accounts`，普通为 `demo: false` 且省略账号字段。`mode: offline` 与是否演示是两个独立含义。

## 1. 注册或登录

普通环境的新用户选择「注册家庭」，填写邮箱、至少 8 位密码与家庭名称；已有账号选择「登录」。注册使用当前设备的时区建立家庭。独立演示环境可以点击「主人演示登录」或「只读演示登录」，按钮使用该演示服务返回的公开合成凭据调用正常登录接口，仍遵循实际家庭权限。访问令牌与刷新令牌只保存在当前标签页的 `sessionStorage`；访问过期后尝试刷新，刷新失效则返回登录。使用「退出」结束当前登录。

账号属于所选数据库。SQLite 与 PostgreSQL 中同名邮箱是否存在由各自数据决定；切换环境后不能用另一个库的令牌继续访问。

## 2. 添加并选择宠物

点击「添加宠物」，选择所属家庭，填写名字、宠物类型，以及可选的品种、生日和体重；保存后选中该宠物。后续概览、照护、活动和设备操作围绕当前宠物，切换宠物后重新读取其数据。没有绑定设备时，可以先创建照护记录。

页面显示真实的空状态。空库首次使用时没有位置、活动、告警或附件，体验台不会自动导入样例或生成遥测。当前家庭权限仍由后端检查；viewer 可以读取，写入操作需要相应权限。

已有宠物可通过宠物栏的「修改资料」更新名字、类型、品种、生日和统计时区；留空时区表示继承家庭。体重在照护记录中维护，以保留每次称重及修订历史。

### 家庭与成员

顶栏点击「家庭」打开「家庭与成员」，可选择当前账号可访问的家庭并查看成员。owner 可以修改家庭名称与统计时区、邀请成员、在 caregiver/viewer 间调整角色或移除非 owner 成员。邀请填写受邀邮箱及角色后生成邀请码，不发送邮件；受邀用户需使用对应邮箱登录，在「加入其他家庭」中提交邀请码接受。邀请码有效七天。

caregiver 可按既有业务权限照护宠物，viewer 可查看共享资料及操作本人的通知已读。修改共享家庭成员或设置仍需 owner；移除成员不会删除其已录入的照护历史。权限以每次 API 的实际结果为准。

## 3. 查看概览、围栏与待办

「日常概览」汇总档案、当前设备与位置、活动和照护，并显示围栏状态、未关闭安全事件、待确认事件和本人未读通知的总数。待办明细受 API 前五条限制，总数可以更大。

在「设备与安全」中点击「添加围栏」，输入名称、圆心纬度、经度和半径建立圆形围栏，读取其有效状态，也可停用已有启用围栏。位置以坐标、时间和质量信息展示，本地版本没有地图底图。没有有效定位、围栏判断过期或数据不足时保持未知，不据此显示安全。

确认安全事件记录家庭的处置事实；标记通知已读只影响本人。事件确认、风险关闭与通知已读分别保存，确认不等于风险消失。修改后重新读取概览反映当前结果。字段口径见 [宠物概览](overview.md)。

### 位置历史与安全事件详情

点击「足迹与事件」查看位置范围查询、局部轨迹示意和位置明细。默认查询最近 24 小时，日期按当前设备时区输入，单次最多 31 天；后续分页复用同一精确范围，不随翻页时钟移动。图只连接同设备、同次绑定、连续质量足够的 GNSS 点，异常点或换绑会断开；没有明确绑定归属的点只显示为散点。历史表和事件关联位置展示采样新鲜度，历史质量足够或采样新鲜不表示宠物当前仍在该位置，也不表示当前绑定仍可追踪。

安全事件独立展示全部历史，不受位置时间范围筛选。列表可加载更早事件，已关闭项显示关闭时间和原因。打开「查看详情」可核对判断依据、关联采样点、家庭确认和本人通知。新记录区分定位确认返回、进入围栏记录、围栏停用或规则修改、设备解绑，以及连接、电量或定位恢复。旧记录缺少原因时显示「未知（旧记录未记录原因）」。

例如，停用围栏后，原越界事件会显示「围栏已停用」；当新定位满足返回判定时，原越界事件才会显示「定位确认已返回围栏」。确认知晓仅记录家庭处置，查看历史不会自动确认事件或标记通知已读。授权导出的 `safety_events.closed_reason` 与页面对应，旧记录为 `null`。

### 通知中心与提醒偏好

打开顶部铃铛「通知中心」或概览里的「全部通知」，可查看当前账号在所有可访问家庭中的本人通知。列表显示宠物名称、已读状态和投递状态，可按「全部」「未读」「已读」筛选并查看更多历史。通过通知可打开关联安全事件。仅打开详情不会标记已读，点击「标为已读」后会更新列表和概览里该宠物的未读数。其他成员的通知和安全事件的确认状态各自独立。

家庭所有者、照护者和只读成员均可在通知中心修改本人的提醒偏好。围栏、电量、设备离线和定位四类可分别开关。关闭一类后，后续该类事件不再生成你的个人通知，该类已有待发送通知也可能跳过投递。历史通知继续保留，安全事件仍可在「足迹与事件」查看。投递状态中的离线模拟和服务商受理仅表示相应通道已处理，手机实际送达仍为未知。

## 4. 记录照护、纠正内容与保存附件

在「照护记录」点击「记录照护」，选择类型和发生时间，填写相应内容后保存。发生时间按当前设备的时区输入，保存时转换为带时区的时间；显示时仍使用设备时区。

| 类型 | 要填写的事实 |
| --- | --- |
| 体重 | kg 数值 |
| 喂食 | 食物名称与喂食量（g） |
| 用药 | 药品名称与已发生的实际用量 |
| 清洁护理 | 本次护理内容 |
| 日常笔记 | 要保留的事项 |
| 排泄 | 排尿、排便或两者 |
| 自定义 | 事项名称及本次内容，例如刷牙或训练 |

每条记录提供「编辑」「历史」「附件」和「撤回」；列表支持按类型与有效/已撤回状态筛选，并可加载下一页。撤回需要填写原因，撤回后的记录及旧版本保留，不能继续编辑或上传附件。原作者或家庭 owner 可以撤回，其他操作沿用 owner/caregiver 等既有权限。页面新建记录使用家庭手工来源，系统不提供用药建议或疾病诊断。

记录保存后点击「附件」，可上传 JPEG、PNG、WebP 或 PDF，每个文件最多 5 MiB，每条记录最多 10 个。图片可以预览，附件可由当前家庭成员下载；撤回记录后仍保留读取，当前没有独立附件删除操作。文件保存在当前数据库中，随备份保存。类型、编辑与附件合同见 [照护类型](care-types.md)、[编辑与撤回](care-withdrawal.md) 和 [照护附件](care-attachments.md)。

## 5. 观察活动

「活动趋势」按所选日期读取日统计和截至该日的过去七天，右侧显示今日同进度观察，今日比较独立于所选历史日期。缺失的步数、活动时间等保持未知，未上报不显示为零；覆盖不足会显示数据缺口。今日比较使用今天零点至当前时点与前七天相同经过时长的窗口，指标须满足覆盖率和历史日期数量要求才给出变化。

「所选日期的活动观察」使用完整自然日。通过「查看日期」选择已结束的一天，也可点击「查看昨天」。当有一条变化观察时，点击「查看证据」，核对指标覆盖、参与比较的日期、来源与计算版本。家庭所有者或照护者填写「反馈说明」，再点击「有用」或「不准确」，对话框显示保存结果。只读成员可核对同一份证据。数据不足时页面保留原因，不提供针对该指标的反馈按钮。反馈记录与提交者关联，可随本人的授权数据导出。

体验台不会生成活动样本，也不根据少量活动给出健康或情绪结论。算法与数据口径见 [今日同进度活动观察](current-observations.md)。

## 6. 认领设备、设置策略与寻找宠物

设备已由维护人员预置后，在「设备与安全」点击「绑定设备」，输入设备 ID 和有效绑定码，将其认领给当前宠物。一个宠物同时绑定一台设备；设备长期令牌不用于主人认领，不应填入页面。

绑定后回到「日常概览」查看「最近位置」。尚未收到可显示的位置时，显示等待首次定位。绑定满 10 分钟仍无可显示位置时，提示检查项圈开机、连接和环境。上报后可点击刷新，采样时间、精度和可用性继续按实际数据展示。

绑定后可通过「调整上报策略」选择模式与上报间隔（15–86400 秒），并开启或关闭走失模式，开启时填写持续时间（1–1440 分钟）。提交成功表示命令已受理，页面继续区分等待执行、已执行、失败或过期，以及执行来源；offline 的 simulator 回执不代表真实项圈已经执行。走失模式启用期间，先关闭再调整普通策略。等待新数据或回执后，点击页面右上方的刷新按钮查看当前状态。

设备所有者可从当前设备页面解绑，确认后保存返回的设备 ID、重新绑定码和有效期，再选择目标宠物重新认领。解绑保留历史资料，但会清除当前设备状态与策略、关闭相关开放事件；新绑定不继承旧宠物的当前状态，需等新上报。新码有效 30 分钟，解绑结果窗口也可重新签发绑定码。普通家庭成员的写权限不等于设备所有权。

### 设置和编辑围栏

在「设备与安全」的「日常活动围栏」点击「添加围栏」。圆形填写中心纬度、经度和半径，多边形按边界顺序逐行填写 WGS84 `经度, 纬度`。多边形至少三个不同且不共线的顶点，首尾可由系统闭合，边界不能自交。页面按坐标录入，适合在离线环境操作。

主人和照护者可以编辑名称、范围、固定或动态缓冲、精度阈值、连续确认点数以及进入、离开持续时间，也可停用或重新启用。只改名称会保留当前判断。改判定规则或切换启用状态后，当前判断回到未知，等待符合规则的新位置。只读成员可查看已有围栏和状态。

### 家庭运行简报与失败处理

在「设备与安全」→「运行与排障」打开「家庭运行简报」，查看当前绑定设备、队列积压、最近 24 小时位置样本质量、三段遥测延迟以及本人通知通道结果。暂无样本时显示未知，位置合格率的分母是已生成的位置记录。

当前宠物有已绑定设备时可打开「遥测失败」，筛选待重试或死信。主人或照护者确认原因已处理后，填写理由并重新排队。Worker 随后处理该消息，可重新打开简报或列表查看进度。只读成员可以查看失败摘要。详细字段口径见 [运行简报](operations.md)。

### 走失位置分享

1. 主人或照护者选中已绑定设备的宠物，在「设备与安全」的「走失模式」面板开启走失模式，再点击「位置分享」。当前走失会话有效时即可创建链接。设备是否已经应用高频上报策略，请以回执为准。
2. 选择分享时限，勾选同意向持有链接的人公开必要位置，再创建。实际到期时间不晚于走失会话结束时间。完整链接仅在创建时显示，请当场复制并自行转交。历史列表可查看分享记录，但无法找回链接。
3. 接收者在可访问当前服务的浏览器打开链接，无需登录。页面显示宠物名称、位置坐标、采样时间、来源和精度，最新点不可用时会区分可用的历史位置。点击刷新可再次读取当前共享状态。`127.0.0.1` 链接只能在运行 DOOGY 的同一台电脑打开。对方使用其他设备时，需能访问该服务的部署地址。
4. 创建者或家庭所有者可撤销分享。撤销、自然到期、关闭走失模式、设备解绑，以及创建者被移除或变为只读后，链接失效。接收者刷新时会看到失效提示。

### 设备预置由维护终端完成

先为所选数据库生成设备身份，序列号应使用本次尚未预置的值：

```powershell
./start.bat .env provision MY-COLLAR-001
```

使用 PostgreSQL 时把 `.env` 换成 `.env.postgres`。维护命令先构建和准备数据库，完成后退出，不启动 API/Worker。保存一次性返回的设备 ID 与绑定码，再正常执行 `start.bat`，在体验台认领。绑定码有效 30 分钟，过期后按 [设备凭证维护](device-credentials.md) 补发。

维护输出还包含设备长期令牌，供设备模拟器或设备维护使用，勿贴入照护记录、截图或应用日志。预置只创建设备身份，不生成位置、活动或告警；已有的离线上报工具和标准事件导入方式见 [README 对接流程](../README.md#保留的硬件接口)。

## 7. 提交工单与客服处理

1. **绑定前求助**。登录后，点击顶部「我的工单」→「绑定前求助」，填写卡住的步骤和页面提示，再提交。该入口只收集文字描述，不需要宠物档案或设备，也不附带诊断。已经绑定设备的账号也可使用该入口。
2. **已绑定设备工单**。选择有绑定设备的宠物，从「我的工单」点击「提交工单」，填写问题类别和描述。只读成员也可为有权访问的设备提交本人问题。诊断授权默认关闭。主动授权后，客服可查看创建时的设备、上报、延迟和告警摘要。快照省略精确坐标、轨迹、围栏几何、设备密钥和原始报文，有效期最长七天。
3. 「我的工单」只列出本人记录，可按待处理、处理中、已解决筛选。打开工单可查看回复和状态历史。已授权的诊断可在详情撤销，工单和回复仍可查看。解绑、失去家庭访问权或到期也会使诊断失效。
4. 管理员通过 `GET /api/v1/auth/me` 核对客服账号 UUID，并在当前服务环境的 `SUPPORT_ADMIN_USER_IDS` 配置授权。客服从顶部「客服处理」查看两类工单、回复，并设为处理中或已解决。仅在设备工单拥有有效授权时，客服可打开诊断快照。提交者重新打开本人详情可查看最新回复。[客服账号配置](../fb.md)

## 8. 自助导出账号与家庭数据

1. 在顶部打开「数据导出」，核对个人账号、当前可访问的家庭与角色，点击分区数展开名称。范围以账号和家庭权限为准，包含清单中的所有家庭。
2. 点击「生成导出文件」，等待记录与分区计数出现，再点击「下载 NDJSON」。文件末行的 `complete` 标记、分区计数与 SHA-256 可用来核对完整性。
3. 若网络、会话或家庭权限问题中断分页，重新打开「数据导出」读取当前清单。附件较多时，可用逐页写入的本地命令导出。[账号数据导出](account-export.md)

## 使用范围

这是通过桌面或窄屏浏览器操作的本地业务客户端。家庭协作、宠物资料修改、设备解绑重绑、位置与事件追溯以及数据导出已接入页面。注销、共享资料删除和部分运营维护通过各自的 API 或本地命令办理。没有原生手机安装包、地图服务或手机推送接入，也没有发布到公网。

按 [验收清单](acceptance.md) 在所选数据库/模式验证真实启动、保存重读和停止范围。
