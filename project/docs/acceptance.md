# 前后端协作验收清单

本文件定义纯净源码版的可重复验收入口，不附原机器的历史测试数字或日志。每次交付将实际结果写入 [协作流程](process.md)；需求和接口分别见 [主需求](../Doggy_final.md)、[fb.md](../fb.md) 和 [51 画板操作表](app-closed-loop.md)。

## 自动化入口

```powershell
# 根目录：最新构建与默认离线回归
npm.cmd ci
npm.cmd test
# App：先具备根依赖，再安装移动依赖和执行检查
cd mobile
npm.cmd ci
npm.cmd test
npx.cmd tsc --noEmit
cd ..
# 已准备独立 PostgreSQL/PostGIS 测试环境时
npm.cmd run test:postgres
```

测试环境仅使用独立合成数据和自己创建的随机数据库。默认回归中的 PostgreSQL 条件跳过不能计为实库通过；专用实库入口没有可用连接时应明确失败。数据库变更需同时验证双驱动迁移和受影响用例，测试不得清空业务库。

## 启动和保存

- 普通启动与独立 App 演示均构建最新源码。构建失败不继续旧输出，服务异常时管理器停止同次启动的其他服务。
- 普通 `.env`、数据模式和业务库保持；演示重复启动新建独立库，重读验收必须用同一个数据库重启。
- 保存按钮等待结果，重复提交沿用同一业务意图的幂等键；失败显示未确认保存，成功后可从列表和详情重读。
- App 冷启动能恢复有效会话，临时身份读取错误允许重试；明确失效、退出或切换服务器时清本机会话。

## 主要软件路径

| 路径 | 成功条件 |
| --- | --- |
| 注册、家庭、宠物与引导 | 可选显示名可留空；建宠后读取失败不重复创建；明确绑定或跳过后保存完成进入首页 |
| Goal / Body 与运动计划 | 同日期/时区分项草稿互不覆盖；冲突保留草稿；计划只预填，显式保存，身体观察保留原文不评分 |
| 照护与营养 | 体重/喂食/如厕/自定义事项可保存、修订、撤回和读取历史；单位、来源、附件和未知能量保持可追溯 |
| 活动与健康观察 | 窗口/时区/覆盖率明确；今日同期与完整自然日分别比较；缺失不解释为正常或未发生 |
| 内容与课程 | 搜索、正文、来源、步骤、本人已学与课程版本可保存和重读；合成内容不是专业审核 |
| 媒体、解释和反馈 | 录制或导入后显式上传；真实格式/时长校验；授权播放、解释排队、历史、取消/重试和本人反馈可重读 |
| 本人问答 | 明确选择可读上下文和本人会话；任务保存、状态和来源有效性可复读；原文证据不冒称模型分析 |
| 设备、安全与联系人 | 库存/认领/解绑找回、版本化策略/回执、定位质量/历史/围栏和通知状态明确；重试取消不复制私有资料 |
| 权限与数据生命周期 | owner/caregiver/viewer、跨家庭、撤权和切宠隔离；源更正/删除使派生失效；授权导出、注销和恢复重放按合同处理 |

## 原生与真实集成

原生终端另验系统文件选择器、权限拒绝与授权、真实录音/自动停止、播放器和可听输出、键盘、前后台、分享、网络失败及退出。组件 SDK 桩证明逻辑分支，不证明这些终端能力。Android ARM64、不同 API、iOS、签名/商店和性能分别记录。

硬件另验协议、令牌、时间/坐标/质量、断网补传、重复/乱序、解绑/重绑、命令与回执及手机离开后的独立上报。真实模型、地图、SSO、推送/短信/邮件或联系人接收必须有真实授权响应与外部证据。
